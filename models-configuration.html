Models Configuration ​

This reference lists the fields of models.json. See Configure a compatible endpoint for examples and Configuration for the file location.

Add "$schema": "https://pi.dev/schemas/models.schema.json" to models.json for editor validation and completion.

Providers ​

Each key under providers is a provider ID. A built-in provider ID changes that provider. Any other ID adds a provider, which needs baseUrl and an api at provider or model level.

FieldTypeDefaultDescription
namestringDisplay name.
baseUrlstringAPI base URL. Also applies to the provider's built-in models.
apiKeystringLiteral key, "$NAME" environment interpolation, or "!command" output.
apistringAPI for the provider's models, such as "openai-completions", "openai-responses", "anthropic-messages", or "google-generative-ai".
oauth"radius"OAuth login flow. Requires baseUrl.
headersobjectRequest headers. Values resolve like apiKey.
compatobjectProvider and model compatibility overrides.
authHeaderbooleanfalseWhether to send the resolved API key as Authorization: Bearer.
modelsobject[]
modelOverridesobject

Compatibility ​

compat describes verified differences from an API's standard request and response behavior. Model values override provider values per field. The fields that apply depend on the model's api.
