快捷键参考 ​

Pi 暴露可绑定快捷键的命名操作，例如 app.session.new。你可以在 Pi 的用户配置中更改默认绑定，或为未绑定的操作添加绑定。

运行 /hotkeys 查看主编辑器和应用的当前快捷键。

绑定快捷键 ​

创建 <agent-dir>/keybindings.json。agent 目录默认为 ~/.pi/agent，详见 Agent 目录。

将每个操作标识符映射到一个键或键列表：

json
{
  "$schema": "https://pi.dev/schemas/keybindings.schema.json",
  "app.session.new": "ctrl+shift+n",
  "app.session.tree": ["ctrl+shift+t", "alt+shift+t"]
}

配置值会替换该操作的默认值。使用空列表禁用某操作的快捷键：

json
{
  "tui.altScreen.pageUp": []
}

编辑文件后，运行 /reload 将更改应用到当前会话。

键语法 ​

按键写作 modifier+key。修饰键是 ctrl、shift、alt 和 super。可以组合修饰键。有效的按键有：

  • 字母： a-z
  • 数字： 0-9
  • 特殊键： escape, esc, enter, return, tab, space, backspace, delete, insert, clear, home, end, pageUp, pageDown, up, down, left, right
  • 功能键： f1-f12
  • 符号： `, -, =, [, ], \, ;, ', ,, ., /, !, @, #, $, %, ^, &, *, (, ), _, +, |, ~, {, }, :, <, >, ?

示例：ctrl+shift+x、alt+ctrl+x、ctrl+shift+alt+x、super+k、ctrl+super+k 和 ctrl+1。

super 绑定要求终端单独上报该修饰键，通常通过 Kitty 键盘协议。在不支持该功能的终端中可能无效。

应用 ​

快捷键 ID默认值描述
app.interruptescape取消 / 中止

app.exitctrl+d退出（编辑器为空时）
