设置参考 ​

本参考列出用户可配置的设置项及其类型、默认值和用途。项目设置覆盖 agent 目录设置。资源列表会合并。文件位置和信任行为见配置。

在 settings.json 中添加 "$schema": "https://pi.dev/schemas/settings.schema.json" 可获得编辑器校验和补全。

模型与思考 ​

设置类型默认值说明
defaultProviderstring自动启动时的 AI 提供商（provider）。
defaultModelstring自动启动时的模型 ID。
defaultThinkingLevel"off" | "minimal" | "low" | "medium" | "high" | "xhigh" | "max""medium"启动时的思考级别（thinking level）。
modelThinkingLevelsobject无按精确的 provider/modelId 设置各模型的启动思考级别。
thinkingBudgetsobject内置预算minimal、low、medium 和 high 思考级别的 token 预算。
enabledModelsstring[]所有可用模型用于启动选择和模型循环切换的模型模式。格式与 --models 相同。
hideThinkingBlockbooleanfalse在对话记录中隐藏思考块。
showCacheMissNoticesbooleanfalse显示显著缓存未命中、缓存预热成功、压缩用量和提供商恢复的通知。
cacheWarming"off" | "streaming" | "idle""streaming"在活跃运行期间（"idle" 则在运行之间）保持符合条件的提供商提示词缓存处于预热状态。仅限全局设置。

缓存预热仅在模型声明了缓存生存期，且 Pi 估计可避免的缓存未命中成本不低于 $0.05 时运行。预热用量计入会话总额，但不进入模型上下文。/session 显示下一次决策；扩展可以通过 cache_warming_decision 覆盖它。见提示词缓存生存期。

模型选择和思考控制见选择模型。

工具 ​

设置类型默认值说明
defaultToolsstring[]read, bash, edit, write启动时启用的工具。普通名称替换默认值；+name 添加工具，-name 移除工具。空数组禁用所有内置工具，但不影响扩展或 SDK 工具。
codemode.mode"on" | "only""on"codemode 工具激活时展示工具的方式。on：在已声明工具的描述后附加从脚本调用的说明，codemode 只列出未声明的工具。only：codemode 列出脚本可调用的所有工具，活跃的内置和扩展工具对模型隐藏，模型需通过 codemode 访问它们。
codemode.inlineBudgetnumber3000codemode 工具描述中可用于工具声明的预估 token 数（字符数 / 4）。放不下的工具会被略过，可通过 searchTools() 查找。0 只列出命名空间。

可用的内置工具有 read、bash、powershell、edit、write、grep、find 和 ls。defaultTools 还可以指定 codemode 和 tool_search（由内置扩展注册为未激活），以及其他注册为未激活的扩展工具。

只包含 +name 和 -name 的列表会修改继承的选择而不是替换它。例如，以下配置在默认工具之外启用 codemode：

json
{
  "defaultTools": ["+codemode"]
}

这会用 powershell 替换 bash 并启用 grep：["-bash", "+powershell", "+grep"]。项目设置叠加在用户设置之上：只含 +name 和 -name 的项目列表修改用户的选择，含普通名称的项目列表则替换它。在同一个列表中，普通名称构成选择，+name 和 -name 随后按顺序生效。

/reload 会启用新加入 defaultTools 的工具，但不会禁用从中移除的工具，也不会重新启用你已关闭的未变动工具。带普通名称的 --tools、--no-tools 和 --no-builtin-tools 会覆盖 defaultTools，/reload 时也是如此。

CLI 工具选项只在单次调用中覆盖此设置。只含 +name 和 -name 的 --tools 会改为修改已解析的 defaultTools 选择，例如 pi --tools +codemode。/reload 时这些条目同样作用于重新加载后的设置，因此用 -name 移除的工具保持移除。见命令行。

设置类型默认值说明

压缩（compaction） ​

设置类型默认值说明
compaction.enabledbooleantrue启用自动压缩。
compaction.reserveTokensnumber16384空闲上下文 token 低于该值时启动自动压缩。
compaction.keepRecentTokensnumber20000不参与摘要、予以保留的近期 token 数。
compaction.modelOverridesobject无按精确的 provider/modelId 设置各模型的 token 配置。

压缩 token 值必须是非负安全整数。每个值依次从匹配的模型覆盖、普通压缩设置、内置默认值中独立解析。项目和用户对象在模型查找之前先合并。

触发、摘要和校验行为见压缩参考。

网络与重试 ​

设置类型默认值说明
transport"auto" | "sse" | "websocket" | "websocket-cached""auto"支持多种传输方式的 AI 提供商的首选传输方式。
httpProxystring无作为 HTTP_PROXY 和 HTTPS_PROXY 应用于 Pi 管理的 HTTP 客户端的代理 URL。只能在 agent 目录设置中配置。
httpIdleTimeoutMsnumber | "disabled"300000HTTP 头和主体的空闲超时（毫秒）。设为 0 或 "disabled" 可禁用。
websocketConnectTimeoutMsnumber | "disabled"15000WebSocket 连接超时（毫秒）。设为 0 或 "disabled" 可禁用。
retry.enabledbooleantrue启用 agent 级自动重试以应对瞬时故障。
retry.maxRetriesnumber3agent 级最大重试次数。
retry.baseDelayMsnumber2000指数退避的初始延迟（毫秒）。
retry.maxAgentDelayMsnumber60000agent 级最大重试延迟（毫秒）。
retry.provider.timeoutMsnumberhttpIdleTimeoutMs提供商请求超时（毫秒）。
retry.provider.maxRetriesnumber0提供商级重试次数。

除非需要提供商级重试，否则请保持 retry.provider.maxRetries 为 0。提供商重试可能延误 Pi 自行处理配额和用量限制错误。

资源 ​

用户设置中的资源路径基于 agent 目录解析。项目设置中的路径基于项目 .pi 目录解析。支持绝对路径和 ~。

设置类型默认值说明
packagesarray[]npm、git 或本地 Pi 包来源。见 Pi 包。
extensionsstring[][]扩展（extension）文件或目录。
skillsstring[][]技能（skill）文件或目录。
promptsstring[][]提示词模板（prompt template）文件或目录。
themesstring[][]主题文件或目录。
enableSkillCommandsbooleantrue将技能注册为 /skill:name 命令。

资源数组支持用 !pattern 排除 glob、用 +path 精确包含、用 -path 精确排除。用户级和项目设置中列出的资源 Pi 都会加载。

内置扩展在 extensions 中名为 builtin:mcp、builtin:llama.cpp、builtin:codemode 和 builtin:tool-search。它们默认加载；-builtin:mcp 可禁用其中一个。项目设置中的 +builtin:<name> 或 -builtin:<name> 条目覆盖用户设置。pi config 会在 Built-in 下列出它们。--no-extensions 也会禁用它们，-e builtin:<name> 可显式加载一个。
