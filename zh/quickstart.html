快速开始 ​

Pi 在终端中运行，操作你机器上的文件。使用它需要通过受支持的提供商（provider）访问模型，可以是订阅、API key 或本地模型。

Windows 原生安装请阅读 Windows 安装。Android 请阅读 Termux 安装。

1. 安装 Pi ​

在 macOS 或 Linux 上，可以使用安装脚本：

bash
curl -fsSL https://pi.dev/install.sh | sh

安装脚本会锁定所有依赖，并通过 pi update 更新 Pi。也可以从 npm 安装 Pi，这种方式不锁定传递依赖。需要 Node.js 22.19 或更新版本：

bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent

正常的 npm 安装不需要运行依赖的生命周期脚本。

在 macOS 或 Linux 上使用 Nix 时，可从 Pi 的 flake 安装最新版本。Nix 从源码构建 Pi：

bash
nix profile add github:earendil-works/pi/stable

较旧的 Nix 版本使用 nix profile install。更新使用 nix profile upgrade pi；pi update 无法更新 Nix 安装。要固定版本，使用标签，如 github:earendil-works/pi/v1.0.0。

验证安装：

bash
pi --version

2. 启动 Pi ​

切换到你想让 Pi 处理的文件夹，然后启动：

bash
cd /path/to/folder
pi

工作文件夹帮助 Pi 发现相关文件、指令和配置。Pi 也用它对已保存的会话（session）分组。

界面显示你的对话、用于输入提示词和命令的编辑器，以及包含当前文件夹、模型和会话状态的底部栏。学习添加文件、运行命令、指导进行中的工作和管理结果，参见 在终端中使用 Pi。

3. 选择模型 ​

模型（model） 生成 Pi 的响应。提供商（provider） 是 Pi 用来访问该模型的服务或账户。

在 Pi 中运行：

text
/login

选择提供商，然后按提示使用订阅或存储 API key。之后如果想选择其他可用模型，运行 /model。

受支持的提供商、环境变量认证、本地模型和自定义端点参见 选择模型和提供商。

4. 给 Pi 一项任务 ​

Pi 会展示它执行的每次文件读取、搜索、命令和编辑。它不会在每次工具调用前询问。

输入一项符合你工作的任务，例如：

text
Summarize @meeting-notes.md and save the action items to action-items.md.
text
Explain how this repository is structured and how to run its checks.
text
Compare @previous.csv with @current.csv and summarize the important changes.

在编辑器中输入 @ 可搜索文件，而无需输入完整路径。Pi 完成后，检查其响应和被更改的文件。重要工作请使用版本控制或备份。对于不受信任或无人值守的工作，请使用容器或其他沙箱。参见 安全。

稍后继续 ​

Pi 会自动保存会话。退出 Pi 后，用以下命令恢复同一工作文件夹最近一次的会话：

bash
pi --continue

使用 /resume 选择其他已保存的会话。会话命名、分支（branch）、压缩（compaction）、导出和共享参见 继续或分支会话。

后续步骤 ​

  • 交互式使用 Pi，学习输入、命令、快捷键和排队消息。
  • 添加指令，让 Pi 在某个文件夹中工作时始终遵循。
  • 选择模型和提供商。

选择定制方式 ​

从满足需求的最简单机制开始：

需求起步方式
为某个文件夹给 Pi 持久指令AGENTS.md
从 / 菜单复用提示词提示词模板
添加任务专属指令和配套文件技能
添加可执行工具、命令或事件处理器扩展
构建自定义终端组件终端 UI
接入不受支持的模型服务自定义提供商
安装或分发多个资源Pi 包

卸载 Pi ​

如果用 npm 安装了 Pi，运行：

bash
npm uninstall -g @earendil-works/pi-coding-agent

如果使用安装脚本，重新运行它并选择 Uninstall Pi：

bash
curl -fsSL https://pi.dev/install.sh | sh

如果用 Nix 安装了 Pi，运行：

bash
nix profile remove pi

以上方式都不会从 ~/.pi/agent/ 移除配置、凭据、会话或已安装的 Pi 包。
