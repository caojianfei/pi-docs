配置 ​

Pi 支持用户级和项目级配置。用户级配置位于 agent 目录，默认为 ~/.pi/agent。项目配置位于工作目录下的 .pi，在授予项目信任后加载。唯一的例外是 sessionDir，Pi 会在解析信任之前读取它以定位会话（session）。

交互模式下，使用 /settings 更改常用偏好。其他选项可让 Pi 更新配置，或直接编辑相应文件。手动更改设置、键绑定、指令或资源后，运行 /reload。

Agent 目录 ​

下文中 agent 目录表示为 <agent-dir>。通过 PI_CODING_AGENT_DIR 环境变量或 SDK 的 agentDir 选项设置其位置。

路径职责
<agent-dir>/settings.json用户级设置，包括偏好、默认值、资源路径和 Pi 包声明。
<agent-dir>/keybindings.json自定义终端 UI 和应用键绑定。
<agent-dir>/mcp.json每个项目都可用的 MCP 服务器。
<agent-dir>/models.json兼容端点、模型和模型覆盖。
<agent-dir>/auth.json已保存的 API key 和 OAuth 凭据。
<agent-dir>/AGENTS.override.md、AGENTS.md、AGENTS.MD、CLAUDE.md 或 CLAUDE.MD跨工作目录应用的用户指令。
<agent-dir>/SYSTEM.md替换 Pi 的默认系统提示词。
<agent-dir>/APPEND_SYSTEM.md向 Pi 的系统提示词添加指令。
<agent-dir>/extensions/用户扩展。
<agent-dir>/skills/用户技能及配套文件。
<agent-dir>/prompts/作为斜杠命令暴露的用户提示词模板。
<agent-dir>/themes/用户主题文件。

项目 .pi 目录 ​

路径职责
.pi/settings.json项目级设置、资源路径和 Pi 包声明。
.pi/mcp.json项目 MCP 服务器。
.pi/SYSTEM.md替换项目的系统提示词。
.pi/APPEND_SYSTEM.md向系统提示词添加项目专属指令。
.pi/extensions/项目扩展。
.pi/skills/项目技能及配套文件。
.pi/prompts/作为斜杠命令暴露的项目提示词模板。
.pi/themes/项目主题文件。

对于 SYSTEM.md 和 APPEND_SYSTEM.md，受信任的项目文件优先于 agent 目录中的对应文件。同名文件不会合并。

上下文文件 ​

上下文文件独立于项目 .pi 配置。Pi 从 agent 目录、工作目录及其父目录加载它们。只要 Pi 在某个上下文文件所在目录或其下层目录中运行，该文件就会生效。

AGENTS.override.md 只在同一目录中替换 AGENTS.md 或 CLAUDE.md。它不会屏蔽来自 agent 目录或其他目录的上下文文件。

上下文文件的发现不需要项目信任。
