在终端中使用 Pi ​

在要工作的文件夹中运行 pi。Pi 使用该文件夹发现文件、指令和配置，并对保存的会话进行分组。如果尚未安装 Pi 或选择模型，请先阅读快速开始。

Pi 在加载项目资源之前可能会询问你是否信任工作文件夹。见项目信任。

转录（transcript）区显示你的提示词、Pi 的响应、工具调用、结果和错误。你在编辑器中编写提示词和命令。页脚显示当前文件夹、会话、模型、上下文用量以及累计用量和费用。

输入提示词 ​

输入请求并按 Enter 发送。使用 Shift+Enter 添加一行，或按 Ctrl+G 在配置的外部编辑器中编写较长的提示词。

要包含文件或图片：

  • 输入 @ 搜索文件并将其添加到提示词中。
  • 按 Tab 补全路径。
  • 粘贴图片，或将其拖入兼容的终端。

跟随 Pi 的工作 ​

Pi 在工作时显示每次工具调用和结果。按 Ctrl+O 展开或收起工具输出。按 Ctrl+T 显示或隐藏思考块（thinking blocks）。

启动页眉列出 Pi 加载的指令和资源。编辑器边框指示当前的思考级别（thinking level）。页脚随模型使用上下文并上报用量而更新。

Pi 不会在每次工具调用前询问。请检查命令和被修改的文件，并在不受信任或无人值守的工作中使用沙箱。见安全。

调整方向 ​

Pi 工作时你可以继续发送输入：

目的操作
调整当前任务输入消息并按 Enter
在当前任务之后追加工作输入消息并按 Alt+Enter
将排队的消息返回编辑器按 Alt+Up
停止当前任务按 Escape

用 Enter 发送的消息会等待当前响应及其工具调用完成，然后引导下一次响应。用 Alt+Enter 发送的后续消息会等待 Pi 完成当前任务。中止操作将排队的消息返回编辑器。

Windows Terminal 保留了一些 Alt 快捷键。Windows 上的替代方案见终端配置。

更改模型或设置 ​

输入 / 搜索可用命令。最常用的命令有：

  • /model 选择模型。按 Ctrl+L 打开相同的选择器。
  • /thinking 选择当前模型使用的推理量。按 Shift+Tab 在支持的级别间循环。
  • /login 和 /logout 管理提供商（provider）访问。
  • /settings 修改常用偏好。

提示词模板、技能（skill）和扩展（extension）可以在同一菜单中添加更多命令。见选择模型、配置或完整的斜杠命令参考。

继续或重新开始 ​

除非禁用了会话持久化，Pi 会自动保存会话。

  • /new 开始新会话。
  • /resume 打开另一个已保存的会话。
  • /name 为当前会话起一个可识别的名称。
  • /session 显示会话的文件、ID、消息数、token 用量和费用。

想在不丢失现有工作的前提下探索另一种方案时，使用 /tree、/fork 或 /clone。使用 /compact 减少发送给模型的对话历史。这些工作流见会话与上下文。

离开 Pi 后，在同一文件夹中运行 pi --continue 可恢复其最近的会话。

运行终端命令 ​

在命令前加 ! 前缀来运行它，并将其输出包含在对话中：

text
!git status

如果希望运行命令但不把输出发送给模型，使用 !!。

复制、导出或分享结果 ​

按 Ctrl+X 或运行 /copy 复制最近一条助手响应。使用 /export 将会话保存为 HTML 或 JSONL。

使用 /share 上传会话并获取查看链接。默认情况下，Radius 认证使该内容对你的 Radius 组织可见；否则 Pi 会通过 GitHub CLI 创建私有的 GitHub gist。sessionShareDestination 设置可以强制指定其中一种目标。分享前请先检查会话，因为它可能包含提示词、工具输出、文件内容以及对话中暴露的凭据。

调整终端 ​

默认的全屏模式让编辑器和状态区域固定，转录区在终端窗口内滚动。常规模式使用终端自身的滚动缓冲区。通过 /settings 或 --tui-mode 选择模式。

终端对鼠标输入、键盘快捷键和内联图片的支持各不相同。平台专属配置见终端配置，所有可配置的快捷键见快捷键。运行 /hotkeys 查看当前会话中生效的快捷键。

收集诊断信息 ​

排查终端渲染或会话状态问题时，运行 /debug。Pi 会将渲染的终端行和当前会话消息写入 agent 目录下的 pi-debug.log。

分享该文件前先检查内容。它可能包含提示词、模型响应、工具输出、文件内容和终端数据。
