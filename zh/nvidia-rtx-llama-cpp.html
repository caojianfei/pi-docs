使用 NVIDIA RTX 和 llama.cpp 运行 Pi ​

NVIDIA Local AI Inference Recipes 提供针对特定 NVIDIA 硬件和模型调优的 llama.cpp 设置。每个配方（recipe）给出一条单模型的 llama-server 命令。Pi 使用的是 llama.cpp 路由器，它可以同时服务和管理多个模型，因此本指南将配方命令转换为路由器预设（preset）。

下面的示例使用 Windows PowerShell。Pi 完整的路由器和模型管理参考见使用 llama.cpp 运行本地模型。

开始之前 ​

  1. 打开配方目录，选择你的硬件、操作系统和模型，然后选择 llama.cpp。查看前提条件和内存需求。保留配方的启动命令，供下文转换使用。
  2. 按照配方的安装说明安装 llama.cpp。配方的设置依赖于其构建方式，例如 CUDA 支持或投机解码（speculative decoding）选项。
  3. 运行 llama-server --help，确认输出中包含 --models-preset。没有它，该构建无法将配方作为路由器预设加载。请使用仍满足配方要求的更新构建。
  4. 按照快速开始安装 Pi。在原生 Windows 上，另见在 Windows 上运行 Pi。

将配方转换为预设 ​

预设列出一个或多个模型的设置。每个分节名会成为 Pi 中显示的模型 ID。将预设保存在 llama-server 旁边，或在启动路由器时传入其完整路径。

将配方命令中的每个选项转换为一行预设：

  • 去掉前导短横线：--ctx-size 65536 变为 ctx-size = 65536。
  • 无值的选项写作 true：--jinja 变为 jinja = true。
  • 去掉值周围的引号和 PowerShell 续行反引号。
  • 省略 --host 和 --port。它们属于路由器命令行。
  • 添加 load-on-startup = true，让路由器在启动时加载模型。
  • 将简写的模型文件选项替换为对应的长预设键：
配方选项预设键
-hfhf-repo
-hffhf-file
-hfrdhf-repo-draft
--spec-draft-modelspec-draft-model

例如，这条配方命令：

powershell
llama-server.exe -hf "unsloth/Qwen3.8-27B-GGUF" `
  -hff "Qwen3.8-27B-UD-Q4_K_M.gguf" `
  -hfrd "z-lab/Qwen3.8-27B-DFlash2-GGUF" `
  --spec-draft-model "Qwen3.8-27B-DFlash2-Q4_K_M.gguf" `
  --no-mmproj `
  --host 127.0.0.1 `
  --port 9931 `
  --batch-size 4096 `
  --ubatch-size 1024 `
  --ctx-size 65536 `
  --parallel 1 `
  -ngl 999 `
  --jinja `
  --chat-template-kwargs '{"preserve_thinking":true}' `
  --spec-type draft-dflash `
  --spec-draft-n-max 7 `
  --spec-draft-backend-sampling

转换为 qwen3.8-27b.ini：

ini
version = 1

[qwen3.8-27b]
load-on-startup = true
hf-repo = unsloth/Qwen3.8-27B-GGUF
hf-file = Qwen3.8-27B-UD-Q4_K_M.gguf
hf-repo-draft = z-lab/Qwen3.8-27B-DFlash2-GGUF
spec-draft-model = Qwen3.8-27B-DFlash2-Q4_K_M.gguf
no-mmproj = true
batch-size = 4096
ubatch-size = 1024
ctx-size = 65536
parallel = 1
ngl = 999
jinja = true
chat-template-kwargs = {"preserve_thinking":true}
spec-type = draft-dflash
spec-draft-n-max = 7
spec-draft-backend-sampling = true

启动路由器 ​

在 llama.cpp 文件夹中打开 PowerShell 并运行：

powershell
.\llama-server.exe --models-preset qwen3.8-27b.ini --host 127.0.0.1 --port 8080

如果配方需要 Hugging Face token，请在启动路由器前在同一个 PowerShell 窗口中设置 $env:HF_TOKEN。路由器首次启动时会下载模型文件。

使用路由器健康检查确认服务器就绪。在 Windows PowerShell 中使用 curl.exe 而不是 curl，后者被 PowerShell 映射为另一个命令。当 /models 列出状态为 loaded 的 qwen3.8-27b 时，模型已就绪。

在 Pi 中使用模型 ​

按照配置 Pi 连接到 http://127.0.0.1:8080。预设分节名即模型 ID，因此在本例中在 /model 中选择 qwen3.8-27b。

NVIDIA 配方的内存设置假设只有所选模型使用 GPU。如果 /llama 显示还有其他已加载的模型，请先卸载它们再使用配方模型。
